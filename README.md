# Shopping list

A simple shopping list in **React + TypeScript** (Vite). Learning project: components, state, and a small UI.

You can add items, check them off, delete them, and hide selected rows.

## Requirements

- Node.js (LTS)

## Run

```bash
npm install
npm run dev
```

Then open the local URL printed in the terminal.

## Stack

`React` · `TypeScript` · `Vite`

Built while learning React.
